#  Event Finder App

A Flutter-based mobile application that helps users discover, reserve, and manage events in their area with ease. This app is designed to improve event visibility and simplify event booking through a clean user interface and real-time updates.



## App Features

-  User authentication (login & registration)
-  Browse and filter events by category, date, or location
-  Book and cancel event reservations
-  View upcoming and past booked events
-  MTN Sandbox API for payment as well as QR Code generation as tickets and Google Maps API for event location 
-  Admin dashboard for event verification/approval as well as rejection
-  Event Management page for managing created vents and generated revenue
-  Mobile-responsive design using Flutter



##  Tech Stack

- **Frontend**: Flutter (Dart)
- **Backend**: Firebase (Authentication, Firestore, Storage)
- **Animations**: Flutter animations and transitions
- **Other**: Google Maps API (LOCATION), Flutter toast for notifications, MTN Sandbox API for payment
